# Mi App Móvil — React Native (Expo) + Firebase

Estructura base del proyecto para el aplicativo móvil del equipo de trabajo.

## Requisitos previos
- Node.js LTS (v20+)
- VS Code
- App **Expo Go** en el celular (para pruebas en dispositivo físico)
- Android Studio con un emulador configurado (para pruebas en PC)

## Instalación

```bash
npm install
```

Instala las dependencias de Firebase y utilidades necesarias:

```bash
npx expo install firebase @react-native-async-storage/async-storage
```

```bash
cp .env.example .env
```
## Ejecutar el proyecto

```bash
npx expo start
```
